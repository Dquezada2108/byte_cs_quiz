# Byte · IB Computer Science

A Duolingo-style practice app for **IB Computer Science, Topic 1: Data Representation, Topic 2: Data Transmission and Topic 3: Hardware**, built from the Kognity question set. Your guide is **Byte**, a little dark-teal computer who cheers when you get it right and frowns when you overflow.

**Play it:** https://dquezada2108.github.io/byte_cs_quiz/

## What's inside

- **5 units, 14 lessons, 87 questions**
  - Number systems: registers, two's complement, logical shifts, binary addition, overflow, hexadecimal
  - Text, sound and images: ASCII and Unicode, colour depth, resolution, sampling
  - Data storage and compression: lossy vs lossless, RLE, file-size calculations
  - Data transmission (Topic 2): symmetric and asymmetric encryption, Caesar cipher, half-duplex, USB, echo check, ARQ, parity checks, check digits
  - Hardware (Topic 3): routers, IPv4, IPv6 and MAC addresses, cloud and secondary storage, input devices, CPU cores and clock speed
- **4 question types:** multiple choice, word-bank fill-in-the-blank, an 8-bit toggle board for binary answers, and typed calculations
- **Duolingo-style flow:** lesson path that unlocks in order, 5 hearts per lesson, missed questions come back at the end, explanation after every answer
- **Progress:** XP, daily goal, day streak and best accuracy per lesson, saved in your browser
- Keyboard shortcuts: `1`–`4` choose an option, `0`/`1` type bits, `Enter` checks and continues
- Light and dark mode, sound effects with a mute button

## Run locally

Open `index.html` in any browser. It's a single file with no build step.
